Neural Networks: MLPs, Training & CNNs

How machines learn patterns from data — from one neuron, through training, to the convolutional architecture behind image recognition.

Read this first: A neural network is many tiny "weighted votes" in layers. Each neuron scales inputs by weights, adds a bias, then applies a non-linear activation. Training measures error with a loss function, then nudges weights downhill via gradient descent and backpropagation. For images, plain networks break — convolution and pooling fix them.

Why Neural Networks for Engineering?

Networks learn the rules from raw data.

Traditional engineering uses physics-derived equations, but many real signals are too messy for a tidy formula. A neural network (NN) instead learns patterns from data by stacking units called neurons: given enough examples it finds the relationship itself.

Lecture by Professor T. J. Lim.

Four engineering applications

🌉 Structural Health Monitoring

Cracks, fatigue and anomalies in bridges and aircraft from sensor signals.

🔎 Automated Defect Detection

Production-line defects from images — faster, more consistent than manual inspection.

🛠️ Predictive Maintenance

Equipment failure forecast from sensor data before it happens.

🤖 Autonomous Control

Control policies for robots, drones and self-driving vehicles from data.

💡
Why it matters: Manual inspection is slow and inconsistent, and physics is hard for messy signals; NNs learn the pattern instead.

Borrowing from Biology: The Artificial Neuron

One neuron: scale, add, then decide.

A neuron copies the biological neuron: signals arrive at dendrites, combine in the cell body, and if strong enough fire down the axon. Arithmetically, inputs are scaled by weights, summed, then passed through an activation.

The perceptron

A single neuron computes the perceptron:

Perceptron (one neuron)
ŷ = σ(w₁x₁ + w₂x₂ + ⋯ + w_K x_K + b) = σ(z)

σ(·) is the activation function, usually non-linear; the weighted sum is z = w₁x₁ + ⋯ + w_K x_K + b.

learned Weights and bias

Weights w₁, …, w_K and bias b are the parameters learned in training.

given Inputs

x₁, …, x_K are features in the first layer, prior-layer outputs in hidden layers.

Output ŷ — only the output layer gives the network output; every other layer feeds the next.
🧠
Remember: A neuron is a tiny "weighted vote" — inputs vote by weight, bias is the threshold, activation decides.

Activation Functions

It squashes the weighted sum into the output.

After summing weighted inputs, a neuron applies an activation function to the raw sum z. Three common choices:

ActivationFormulaOutput rangeTypical use
Sigmoidσ(z) = 1 / (1 + e⁻ᶻ)(0, 1)Classic output probabilities
Tanhtanh(z)(−1, 1)Zero-centred — hidden layers
ReLUmax(0, z)[0, ∞)Cheap, effective; default today
S · T · R
“Sigmoid, Tanh, ReLU”
The three common activations.

Non-Linearity and Stacking Neurons

Without non-linearity, a deep network is still a line.

Activations exist for non-linearity. Without one, even a deep multi-layered system collapses into a linear model that cannot represent cognitive systems; with them, complexity lets us mimic image recognition.

ℹ️
Key idea: Stacking linear layers gives another linear layer; non-linearity lets depth buy expressive power.

Stacking neurons: the multilayer perceptron

Stack neurons into layers and you get a Multi-Layer Perceptron (MLP) — a feedforward network, each layer feeding forward. The lecture example:

Hidden layer 1 · 4 neurons→ Hidden layer 2 · 4 neurons→ Output layer · 2 classes

What is the network learning?

An MLP synthesises non-linear decision boundaries separating classes; more layers and neurons make them more flexible. This is blessing and curse:

  • With sufficient data it solves complex classification problems it has never seen.
  • With insufficient data it may overfit and generalise poorly.

We return to overfitting later.

Loss Functions: Measuring How Wrong We Are

The loss turns "how wrong" into one number.

In supervised learning, classification maximises P(y = ŷ) and regression minimises E[(y − ŷ)²]. We define a loss function to minimise over parameters θ. Regression uses MSE (mean square error); classification uses cross entropy, since raw error probability is unsuitable.

Regression → MSE

Continuous target; penalises average squared gap.

Classification → Cross entropy

Class target; penalises confident wrong probabilities.

Mean Squared Error (MSE)

In regression ŷ = f_θ(x), so (y − ŷ)² depends on θ. We want the θ minimising its average over x and y; with only training data we approximate over all samples:

Mean squared error
L(θ) = (1/N) Σᵢ (yᵢ − ŷᵢ)² for i = 1 … N

It is not a simple function of θ, so it needs iterative training.

Cross entropy

In classification y has L values; the model must output a distribution over them:

A valid distribution
p₁, …, p_L such that Σₗ p_l = 1 for l = 1 … L

We want max(p₁, …, p_L) = p_y, the probability on the true label, high — but that gives no way to find θ. So we use entropy: the cross entropy of P and Q over discrete space 𝒮 is:

Cross entropy
H(P, Q) = − Σ_{x∈𝒮} P(x) log₂ Q(x)

Minimal when P = Q, it behaves like a distance.

The elegant one-hot result

If 𝒮_y = {1, 2, 3, 4} and y = 2, the true distribution is one-hot: p₁ = p₃ = p₄ = 0, p₂ = 1. Only the label term survives, so cross entropy collapses to:

Cross entropy for a one-hot label
H = − log₂ p̂_y

Because p̂_y is the y-th model output, it links explicitly to θ. Worked: p̂₂ = 0.7 gives −log₂ 0.7 ≈ 0.515 bits; at 0.99, ≈ 0.0145 bits.

⚠️
Common trap: Don't use MSE on a class label or cross-entropy on a continuous target — match the loss to y.

Training by Gradient Descent

The gradient points uphill; we step the opposite way.

MSE and cross-entropy are differentiable in θ, but the stationarity condition can't be solved algebraically:

We can't solve this directly
∇L(θ) = dL/dθ = 0

Instead we step in the direction of steepest descent.

  • Steepest ascent is ∇L(θ), so steepest descent is its negative. With step size (the learning rate) μ:
Steepest-descent update
θ_{t+1} = θ_t − μ ∇L(θ_t)

Iterate until a stopping criterion — e.g. θ changes by less than a threshold, or a maximum iteration count.

💡
Why it matters: Gradient descent is the engine of NN training: the gradient points uphill, and you step the opposite way, scaled by the learning rate.
🤔
Pause & predict: If the gradient is zero, what has the iteration found — and is it the global minimum?

Batch, Mini-Batch and Stochastic Gradient Descent

All samples is slow, one is noisy; mini-batch sits between.

Both losses average over the whole training set and gradient cost grows linearly with N, so batch processing is slow. Instead we use a mini-batch:

Mini-batch loss
L_batch(θ) = (1/N_b) Σ_{i ∈ mini-batch} lᵢ(θ)

with N_b ≪ N the batch size and lᵢ(θ) the per-sample loss.

The three variants

MethodMini-batch sizeMeaning
Batch GDN_b = NAll samples per step
Mini-Batch GD2 ≤ N_b < NMore than 1, fewer than all
Stochastic GDN_b = 1One sample per step

SGD is often used loosely for mini-batch GD. Treat N_b as a trade-off: smaller means noisier but faster updates. scikit-learn defaults to N_b = 200 (batch_size).

Epochs and batches

One complete pass through the data is an epoch; the number is arbitrary, set by time and compute. Weights update once per mini-batch, repeated over epochs.

🧠
Remember (BMS): Batch = all N; Mini = between 1 and N; Stochastic = exactly 1 sample per step.

Choice of Step Size (Learning Rate)

The single most important knob in training.

The learning rate μ controls each step's size. Three regimes:

🐢 Too small

Crawls toward the minimum, wasting time.

✅ Just right

Converges quickly and smoothly.

💥 Too large

Overshoots, oscillating or diverging.

Optimizers like Adam adapt the step size automatically.

✅
Do this: Loss bouncing or exploding means the rate is too large; barely moving means too small. Use Adam when unsure.

Overfitting and Regularization

Memorising training data makes a model useless on new data.

With more parameters than training data — e.g. 1000 weights but 500 samples — the loss can drop by matching every training input to its class. This is extreme overfitting, and generalisation will be poor.

How to fight it

  • Ensure training samples exceed parameters — the obvious first defence.
  • Overfitting often comes from the underlying model being simpler than assumed — and we don't know it.
  • Drive small, redundant weights toward zero by penalising the norm of the parameter vector — regularization.
💡
Why it matters: A flexible model fits noise as easily as signal; enough data plus a norm penalty keeps flexibility in check.
🤔
Pause & predict: 100% on training but 60% on test: overfitting or underfitting, and what would you change?

Backpropagation

The chain rule, applied backwards from the output layer by layer.

SGD needs the loss gradient for every weight, via the chain rule of differentiation, from the output layer moving backwards — hence backpropagation. For an output-layer weight:

Output-layer neuron
ŷ = σ(w₁x₁ + ⋯) = σ(z)

Applying the chain rule:

Chain rule for a weight
dL/dw₁ = (dL/dŷ) · (dŷ/dw₁) = (dL/dŷ) · σ'(z) · x₁

All right-hand terms can be calculated; hidden-layer weights work the same way.

🧠
Remember (CBO): Chain rule, Backwards from Output. Forward pass to predict, backward pass to assign blame to each weight.

Why Images Are Problematic for MLPs

MLPs discard the spatial structure images depend on and explode in size.

An MLP treats features as a flat list: swapping two leaves the result unchanged — adjacency carries no information. Fine for independent measurements, disastrous for images where nearby pixels relate. Feeding an image means flattening the 2D matrix into a 1D vector, creating two problems.

ProblemWhat goes wrong
1. Parameter explosionA 128 × 128 grayscale image becomes 16,384 features; a 128-neuron first hidden layer needs over 2 million weights.
2. No shift invarianceA detail shifted one pixel isn't recognised — no notion of "same pattern, moved".
The arithmetic behind problem 1
128 × 128 = 16,384 inputs; 16,384 × 128 = 2,097,152 weights
💡
Why it matters: Flattening destroys spatial structure and explodes parameters; CNNs keep 2D structure and share weights.

Convolution: Filtering to Reveal Features

A small filter slides over the image, lighting up its pattern.

Convolution (linear filtering) is nothing new — a filter can amplify colours or sharpen edges. Its effect depends on the filter kernel w_{j,k}, whose weight count is user-defined:

2D convolution
y_{m,n} = Σ_j Σ_k w_{j,k} · x_{m−j, n−k}

The kernel is a small window sliding across the image, summing weighted overlapping pixels.

The vertical edge detector

The lecture's illustrative kernel is a vertical edge detector: it responds strongly where a vertical edge appears (e.g. 10, 10, 0) and weakly with no transition. Different kernels yield different feature maps — original, vertical edges, horizontal edges, blur.

The CNN convolutional layer

A CNN's convolutional layer uses kernels learned from data, not hand-designed — for a furry-animal task, "furriness" may beat "vertical edge". This automatic feature extraction solves the 2nd MLP problem (shift invariance), not complexity; max pooling does.

ℹ️
Key idea: A learned kernel is just weights. Since it slides everywhere, a feature is detected wherever it appears — shift invariance for free.

Pooling and the LeNet-5 CNN

Pooling shrinks each feature map while keeping the evidence.

Images carry redundancy — edges, colours and textures span multiple pixels — and so do feature maps. We collapse a small region to one number: in a 2 × 2 square keep the largest. This is max pooling, solving the 1st MLP problem, parameter explosion. Average pooling keeps the average.

Max pooling

Keeps the strongest activation — the clearest evidence the feature was found.

Average pooling

Keeps the region average; smoother but less selective.

Max pooling, 2 × 2
[[0.2, 0.9], [0.4, 0.1]] → 0.9 (strongest activation kept)

Inputs to the next layer drop by a factor of 4 with little lost — 128 × 128 becomes 64 × 64 after 2 × 2 pooling.

LeNet-5: the pioneering CNN

The lecture highlights LeNet-5, the pioneering CNN and template for modern CNNs:

Input image→ Convolutional layer (learned kernels)→ Max pooling→ … layers …→ Softmax output
🧠
Remember (CP): Convolution fixes Position (same pattern, any location); Pooling fixes Parameter count (shrink the map). Together they make image recognition practical.

Softmax: Turning Scores into Probabilities

Softmax normalises raw scores into a valid distribution.

With L labels, a model outputs probabilities p₁, …, p_L, where p_l is its confidence the label is l. Forward propagation yields values that don't sum to 1; the fix is softmax:

Softmax
softmax_i(z₁, …, z_L) = e^{z_i} / Σₗ e^{z_l} for l = 1 … L
  • Inputs can be any real value — negative or positive.
  • Exponentiation magnifies the gap between largest and smallest.
  • It has a simple derivative in any z_i, which backpropagation needs.

Worked examples: dog, cat or airplane

Example 1. Raw outputs (2.0, 1.0, 0.1) give softmax (0.659, 0.242, 0.099); the top-two ratio rises from 2 to 2.72. Check: e² = 7.389, e¹ = 2.718, e^0.1 = 1.105, sum 11.212, 7.389 / 11.212 ≈ 0.659.

Example 2. Raw outputs (1, 2, 8) mean higher confidence; softmax accentuates it to (0.001, 0.002, 0.997).

💡
Why it matters: Networks output raw scores, not probabilities; softmax makes a valid distribution for cross-entropy loss.

Parameters vs Hyperparameters (and the Code)

The model learns parameters; you choose hyperparameters.

Two ideas sound like "settings"; keep them apart:

ParametersHyperparameters
What they areWeights w and bias bSettings chosen before training
Who sets themLearned from data during trainingChosen by the human designer
Examplesw₁, …, w_K, bLearning rate μ, mini-batch size N_b, epochs, layers/neurons, kernel size

Parameters are learned by minimising the loss with SGD and backpropagation; hyperparameters shape training — batch size, step size, training length, network size. Epochs are arbitrary, set by time and compute.

The hands-on code

The lecture closes with scikit-learn and PyTorch examples. scikit-learn's mini-batch size defaults to 200 (batch_size); optimizers like Adam remove manual step-size tuning.

⚠️
Common trap: Most training mistakes come from hyperparameters — step size, batch size, epochs — not learned parameters. Tune those first.

Key Takeaways

9

10

11

12

Glossary

Every term you need to speak this week's language.

Neural network (NN)
A machine-learning model, loosely inspired by the brain, that learns patterns directly from data by stacking simple units called neurons.
Perceptron
The full computation of a single neuron: ŷ = σ(Σ w_k x_k + b). The basic building block of a network.
Activation function
A usually non-linear function σ(·) applied to a neuron's weighted sum to produce its output; it is what gives the network non-linearity.
Sigmoid
An activation, σ(z) = 1/(1+e⁻ᶻ), that squashes values into (0,1) — classically used for output probabilities.
Tanh
An activation, tanh(z), that squashes to (−1,1). It is zero-centred, so it is common in hidden layers.
ReLU
An activation, max(0, z): cheap and effective, the default choice for hidden layers today.
Multi-Layer Perceptron (MLP)
A feedforward neural network that stacks neurons into hidden layers and an output layer; the most straightforward NN.
Non-linearity
The property introduced by activation functions that lets a network model complex, curved relationships; without it, even a deep network is linear.
Decision boundary
The surface separating classes in the input space. More layers and neurons let an MLP synthesise more flexible non-linear boundaries.
Loss function
A differentiable measure of how far the model output is from the ground-truth label, minimised over the parameters during training.
Overfitting
Fitting the training data so closely (e.g. more parameters than samples) that generalisation to new data becomes poor.
Parameter
A value learned from data during training — specifically a weight w or bias b.
Hyperparameter
A setting chosen by the designer before training — such as learning rate, mini-batch size, epochs, or architecture.
Gradient descent
The method that repeatedly steps in the direction of steepest descent (the negative gradient) to minimise the loss.
Learning rate (μ)
The step size controlling how far each gradient-descent update moves; too small crawls, too large overshoots or diverges.
Epoch
One complete pass through the entire training dataset; the number of epochs used is arbitrary.
Stochastic / mini-batch GD
Gradient descent using a subset of samples per step: mini-batch uses 2 ≤ N_b < N, stochastic uses N_b = 1; "SGD" is often used loosely for mini-batch GD.
Backpropagation
Computing every weight's gradient via the chain rule, moving backwards from the output layer to the input.
Regularization
Penalising the norm of the parameter vector — adding a term that drives small, redundant weights toward zero to reduce overfitting.
Convolution
A linear filtering operation, y_{m,n} = Σ_j Σ_k w_{j,k} x_{m−j,n−k}, where a small kernel slides over the input to reveal features.
Max pooling
Collapsing a feature-map region (e.g. 2 × 2) to its largest value, cutting the next layer's inputs by a factor of 4 to fight parameter explosion.
Softmax
A normalisation, e^{z_i} / Σ_l e^{z_l}, that converts L raw scores into a probability distribution summing to 1.
Mean Squared Error (MSE)
The regression loss (1/N) Σ (yᵢ − ŷᵢ)², the average squared error over the training data.
Cross entropy
The classification loss and a distance between distributions, H(P,Q) = −Σ P(x) log₂ Q(x); for a one-hot label it reduces to −log₂ p̂_y.

Practice Questions

Look away from the page first — retrieval is what builds memory.

Answer, reveal, then tick “Mastered”. Your progress is saved.
Q1

Why is a non-linear activation function essential in a neural network?

Answer: Without an activation function, even a complex multi-layered system remains linear and cannot model cognitive systems or other complex systems. Adding non-linearity lets increasing the network's complexity mimic cognitive functions such as image recognition.
Q2

Write the perceptron equation and identify which quantities are learned parameters.

Answer: ŷ = σ(w₁x₁ + ⋯ + w_K x_K + b) = σ(z). The weights w₁, …, w_K and the bias b are the parameters learned during training; the inputs x are features (first layer) or prior-layer outputs (hidden layers).
Q3

Compare the three common activation functions: sigmoid, tanh and ReLU.

Answer: Sigmoid 1/(1+e⁻ᶻ) squashes to (0,1) and is classically used for output probabilities. Tanh tanh(z) squashes to (−1,1), is zero-centred, and is common in hidden layers. ReLU max(0,z) keeps positives, zeroes negatives, is cheap and effective, and is the default for hidden layers today.
Q4

Distinguish parameters from hyperparameters, with examples of each.

Answer: Parameters (weights and bias) are learned from data during training. Hyperparameters (learning rate, mini-batch size, number of epochs, architecture/layers/neurons, CNN kernel size) are chosen by the designer before training.
Q5

Which loss function suits regression versus classification, and why?

Answer: Regression uses MSE, L(θ) = (1/N) Σ (yᵢ − ŷᵢ)², because the model outputs a continuous estimate. Classification uses cross entropy because the model outputs a probability distribution over L labels; the raw probability of error is not a suitable objective, so cross entropy is the proxy.
Q6

Using 𝒮_y = {1,2,3,4} and true label y = 2, explain why cross entropy becomes −log₂ p̂_y, and compute it for p̂₂ = 0.7.

Answer: The true distribution is one-hot: p₁ = p₃ = p₄ = 0, p₂ = 1. In H(P,Q) = −Σ P(x) log₂ Q(x), only the x = 2 term survives, leaving −log₂ p̂₂. For p̂₂ = 0.7, loss = −log₂ 0.7 ≈ 0.515 bits; at p̂₂ = 0.99 it is ≈ 0.0145 bits.
Q7

State the gradient-descent update rule and explain the stopping criterion.

Answer: Steepest ascent is ∇L(θ), so descent is its negative. With learning rate μ, update θ_{t+1} = θ_t − μ∇L(θ_t). Iterate until a stopping criterion is met — e.g. θ changes by less than a threshold, or a maximum number of iterations is reached. We cannot solve ∇L(θ) = 0 in closed form.
Q8

Distinguish batch, mini-batch and stochastic gradient descent. What is an epoch, and what is scikit-learn's default batch size?

Answer: Batch GD uses all samples per iteration (N_b = N); mini-batch GD uses 2 ≤ N_b < N; stochastic GD uses one sample (N_b = 1). Smaller N_b is noisier but faster and less complex per update. An epoch is one complete pass through the training data, and its number is arbitrary. scikit-learn's default is N_b = 200, resettable via batch_size.
Q9

What happens if the learning rate is too small or too large? How do you avoid choosing it manually?

Answer: Too small: training crawls toward the minimum. Too large: it overshoots and can oscillate or even diverge. Just right: it converges quickly and smoothly. You avoid manual tuning by using adaptive optimizers such as Adam, which adjust the step size automatically.
Q10

Explain overfitting with the 1000-weights / 500-samples example, and how to reduce it.

Answer: With more parameters (1000 weights) than training samples (500), the network can drive the loss down by matching every training input perfectly to its class — an extreme case of overfitting, with poor generalisation. Reduce it by ensuring training samples exceed parameters, gathering more data, and penalising the norm of the parameter vector (regularization) to shrink small, redundant weights toward zero.
Q11

What is backpropagation, and write the chain-rule expression for an output-layer weight.

Answer: Backpropagation computes the gradient of the loss with respect to every weight using the chain rule, starting at the output layer and progressing backwards. For an output-layer weight, dL/dw₁ = (dL/dŷ) · (dŷ/dw₁) = (dL/dŷ) · σ'(z) · x₁; all terms on the right can be calculated.
Q12

State the two problems of feeding an image to an MLP, and do the parameter arithmetic for a 128 × 128 grayscale image with a 128-neuron first hidden layer.

Answer: (1) Parameter explosion: flattening a 2D image into a 1D vector creates huge input counts. (2) No shift invariance: a detail shifted by one pixel is not recognised as the same pattern, because adjacency is lost. Arithmetic: 128 × 128 = 16,384 inputs; with 128 neurons that is 16,384 × 128 = 2,097,152 weights — over 2 million in the first layer alone.
Q13

How do convolution and pooling address the two MLP image problems? Include the factor-of-4 reduction.

Answer: Convolution solves the shift problem: kernels are learned from data and slide over the image, so a feature is detected regardless of position. Pooling solves parameter explosion: max pooling collapses a 2 × 2 region to its largest value, reducing the next layer's inputs by a factor of 4 (e.g. 128 × 128 → 64 × 64) while keeping the strongest evidence the feature was found. LeNet-5 is the pioneering CNN.
Q14

What does softmax do, why is it preferred, and what are the outputs for raw scores (2.0, 1.0, 0.1)?

Answer: Softmax normalises L raw scores into a probability distribution that sums to 1. It is preferred because it accepts any real input, exponentiation magnifies the gap between the largest and smallest values, and it has a simple derivative with respect to any z_i. For (2.0, 1.0, 0.1) the output is (0.659, 0.242, 0.099) — the top-two ratio grows from 2 to 2.72.
