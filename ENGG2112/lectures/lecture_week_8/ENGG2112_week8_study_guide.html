Generative AI: How Deep Learning Models Actually Work

This week opens the black box behind ChatGPT and Copilot — from one neuron to a model that writes one token at a time.

The Big Picture

One idea runs through the lecture: learning is repeatedly adjusting numbers until errors shrink.

A model is not a database of facts; it is numbers tuned so that, given an input, it produces a useful output.

Deep Learning Networks: The Core Idea

A deep learning network is many connected processing units that learn patterns from data by adjusting weights.

A deep learning network is a neural network of many connected processing units. It follows no hand-written rules; it learns patterns by adjusting numerical values called weights.

The recipe repeats: pass data through layers of nodes, measure the error, then backpropagate so predictions improve.

The six key terms for this topic

Nodes (neurons)

Units that transform inputs into outputs.

Layers

Input, hidden and output organisation.

Weights

Dials on connections, tuned by training.

Training

Teaching accurate predictions.

Backpropagation

Updates weights from the error.

Learning over time

Repeated cycle that reduces error.

Inside a Node

A node weighs its inputs, adds them up and decides how strongly to fire.

Nodes, also called neurons, are the basic computational units; each does the same small job, so networks scale to millions.

Every node does five things

  1. Receives numerical inputs from the previous layer or data.
  2. Multiplies each by its weight — bigger weight, bigger influence.
  3. Sums the results into one number.
  4. Applies an activation function — the non-linear rule deciding how strongly it fires.
  5. Produces an output for the next layer.
What one node computes
output = f( w₁·x₁ + w₂·x₂ + … + b )

x₁, x₂ … are inputs; w₁, w₂ … their weights; b a bias; f the activation function.

Worked example: one node

A node gets inputs 2 and 3, weights 0.5 and 0.4.

  1. Multiply: 2 × 0.5 = 1.0; 3 × 0.4 = 1.2.
  2. Sum: 1.0 + 1.2 = 2.2.
  3. Activate: apply the activation function to 2.2.
  4. Learn: if wrong, backpropagation adjusts 0.5 and 0.4 for a better next prediction.

Nodes represent learned features: early nodes pick up simple patterns, later ones combine them into complex concepts.

R · M · S · A · P
“Receive, Multiply, Sum, Activate, Produce”
The five steps every node performs, in order.

Layers and Depth

“Deep” means many hidden layers stacked between input and output.

Networks are organised into layers; each passes information forward, making a pipeline of transformations.

LayerWhat it does
Input layerReceives raw input: pixels or token IDs.
Hidden layersIntermediate processing and feature extraction; many make the network “deep”.
Output layerProduces the final prediction.
⚠️
Common trap: “Deep” does not mean complicated maths — it means many hidden layers.
🧠
Remember — IHO: read left to right like an assembly line: Input feeds Hidden, which feeds Output.

Weights and Parameters

Weights are the dials on every connection; learning finds better values for them.

Weights are numbers on connections between nodes, each controlling how strongly one node influences another; learning finds better values while the architecture stays fixed.

Large models can have millions or billions of weights.

“Parameters” means weights

OpenAI reports 400B parameters and Google 600B — both count weights. More parameters can mean more capacity, a larger potential to fit complex patterns. Those parameters are the model's features: generating text, translating, summarising.

⚠️
Common trap: Parameters are not stored documents; the training text's patterns are absorbed into the weights, not saved as-is.
Capacity — the rough ceiling on how complex a pattern set a model can represent. More parameters usually means more capacity, but it is a potential, not a guarantee.

Training, Loss and Backpropagation

Training is trial and error with a scoreboard: show an example, let it guess, then say how wrong it was.

What training involves

Training teaches accurate predictions: provide input data, produce a prediction, compare it to the correct answer.

The goal is to minimise error via a loss function — a score of how far the prediction is from the truth. Training runs over many examples and repetitions, and repeated cycles steadily reduce error.

The core learning cycle

  1. Forward pass. Feed the input through the network to predict.
  2. Loss calculation. Measure how wrong the prediction is.
  3. Backpropagation. Adjust the weights to reduce that error next time.

How backpropagation works

Backpropagation updates weights. Once the loss is known, it works out which weights are to blame, and by how much:

  • Calculate how much error each weight contributed to the output.
  • Send that error information backwards through the network, output toward input.
  • Adjust each weight slightly to reduce future error.

Backpropagation tells each weight how to change to make the network better.

F · L · B
“Forward, Loss, Back”
The repeated training cycle: forward pass, loss calculation, backpropagation — then again.
✅
Exam tip: If asked what training optimises: the loss function — weights are adjusted to make loss as small as possible.

The Two Phases of a Large Language Model

Every LLM lives two lives: it trains once, then generates forever.

Large Language Models use a two-phase process: training (learn the weights) and generating (frozen weights produce text). This Transformer is the same family that powers ChatGPT.

Phase 1 — Training

  • Data collection and tokenization.
  • Format tokenized data into input–output pairs.
  • Train a Transformer to predict output from input.
  • Fine-tune on specific tasks.

Phase 2 — Generating

  • Tokenize the input text.
  • Predict the next tokens.
  • Sample a token from the distribution.
  • Append and repeat until a stopping criterion.
ℹ️
Key idea: Training changes the weights; generating holds them fixed. A prompt never changes the model — it only steers the output.

Pretraining: The Eight Steps

Pretraining soaks up general language from massive text before the model is adapted to any specific task.

Pretraining learns general language patterns from massive text before task adaptation, in eight steps.

  1. Data collection. Gather large, diverse corpora — web pages, books, Wikipedia, articles.
  2. Data cleaning and filtering. Remove duplicates, low-quality, corrupted or non-linguistic text; filter by language, length and formatting. Garbage in, garbage out.
  3. Tokenization. Convert text into tokens and numerical IDs.
  4. Creating training objectives. Decide what the model predicts.
  5. Transformer initialisation. Define the architecture; set weights randomly.
  6. Training with backpropagation. Run the forward/loss/backward loop at scale.
  7. Learning language representations. Form internal understanding of language.
  8. Pretrained model output. Produce a general-purpose model.
C · C · T · O · I · T · L · P
“Collect, Clean, Tokenize, Objectives, Initialise, Train, Learn, Produce”
The eight pretraining steps in order.

Tokenization: Turning Text into Numbers

Computers cannot multiply words, so tokenization chops text into pieces and numbers each one.

Goal: convert text into a mathematically processable format:

  • Convert raw text into tokens.
  • Tokens may be words, subwords or character sequences.
  • Build a vocabulary of tokens.
  • Map each token to a numerical ID.

It connects text → symbols → numbers: like chopping a sentence into LEGO bricks, each with a catalogue number.

Example of tokenization

A prompt is converted into tokens using the same tokenizer used during training; those tokens become the Transformer's input sequence.

A prompt becomes a list of token IDs
“Large language models work by…” → [1987, 10234, 845, 563, …]
ℹ️
Key idea: The same data can be split into different token sets; as long as training and generation use the same tokenizer, the model stays consistent.

Training Objectives: What the Model Is Asked to Predict

No humans label the data — the text supervises itself.

The model uses unsupervised learning: no human labels, because the text provides the supervision. Two objectives:

ObjectiveUsed byTask
Next-token predictionGPT-style modelsGiven previous tokens, predict the next.
Masked-language modellingBERT-style modelsPredict missing tokens in a sentence.
💡
Why it matters: Because the answer sits in the text, you can train on unlimited data without paid labelling — the trick that made LLMs possible.

The Transformer and Self-Attention

The Transformer lets a model weigh every word against every other word at once.

Before training, the architecture is defined. The Transformer has four component types:

Embedding layers

Map each token to a vector of meaning.

Positional encoding

Adds order and distance so it knows where each token sits.

Multi-head self-attention

Lets every token weigh its relation to others from several perspectives.

Feed-forward layers

Transform each position's representation into richer meaning.

At initialisation the parameters (weights) are random, from millions to hundreds of billions. Structurally a Transformer is a deep network: input → hidden layers → output, with neurons and weighted connections.

Self-attention: how tokens relate

Self-attention is the core. For each token the model compares it with all other tokens, computes attention scores for relevance, and weights important tokens more heavily. This tracks long-range dependencies, resolves ambiguity (what “it” refers to) and uses context dynamically.

Training the Transformer with backpropagation

For each batch of tokenized text:

  1. Tokens pass through the Transformer.
  2. The model predicts token probabilities.
  3. A loss function measures error.
  4. Gradients are computed by backpropagation.
  5. Parameters are updated by an optimizer.

Repeat over many epochs and massive datasets.

What the model learns along the way

Training implicitly teaches grammar and syntax, semantics and meaning, long-range context, and patterns across domains.

Fine-Tuning After Pretraining

Pretraining teaches general language; fine-tuning points that skill at one specific job.

After pretraining, the model can be fine-tuned — adapted to specific tasks. Two primary approaches:

Feature extraction (repurposing)

  • Treats the pretrained LLM as a fixed feature extractor.
  • Existing language features are repurposed.
  • Only the final layers train; the rest stays frozen.
  • Cost-effective and efficient.

Full fine-tuning

  • Trains the entire model on task data.
  • All layers are adjusted.
  • Best when the dataset is large and significantly different from pretraining.
  • More profound adaptation, but resource-heavy.
✅
Do this: Ask how big my labelled dataset is and how different my task is from general language. Small and similar → feature extraction; large and different → full fine-tuning.

Generating Text with a Pretrained LLM

Prompting an LLM turns your words into tokens and predicts what comes next, one token at a time.

Input is tokenized

The prompt becomes tokens using the training tokenizer; they form the Transformer's input sequence, e.g. “Large language models work by…” → [1987, 10234, 845, 563, …].

Tokens are embedded and positioned

Each token maps to a vector embedding of its meaning, and positional encoding adds word order and distance — giving the model what tokens are and where they occur.

Attention, then Transformer layers

Self-attention weights the most relevant tokens. The input then passes through multiple Transformer layers, each with multi-head self-attention and feed-forward networks. No learning occurs — the weights stay fixed (pretrained).

Predicting the next token

The output is a probability distribution over the vocabulary:

Example distribution over the vocabulary
“model” → 0.42 “system” → 0.21 “process” → 0.11

Sampling a token

A sampling strategy selects the next token:

  • Greedy decoding — take the highest-probability token.
  • Temperature scaling — flatten or sharpen the distribution.
  • Top-k or top-p sampling — choose from the most likely candidates.

This balances coherence against creativity.

The autoregressive generation loop

The selected token is appended, fed back into the Transformer, and used to predict the next. This repeats until a stop token or maximum length — which is why LLMs are autoregressive.

T · E · A · P · R
“Tokenize, Embed, Attend, Predict, Repeat”
The autoregressive generation pipeline for a pretrained LLM.

GPT vs BERT: Generate or Understand

Same Transformer DNA, opposite goals — one writes forward, the other reads both ways.

GPT — Generative Pre-trained Transformer

  • Autoregressive; each token sees only earlier tokens.
  • Trained by Next-Token Prediction from all previous tokens.
  • Goal: generate language.

BERT — Bidirectional Encoder Representations from Transformers

  • Fully bidirectional; every token attends to all others.
  • Trained by Masked Language Modelling: hidden tokens are predicted.
  • Goal: understand language.
⚠️
Common trap: GPT is not “better” than BERT — different jobs. Next-token prediction drives generation; masked language modelling drives understanding.

Foundation Models, Implementations and Copilot

A foundation model is a large general model adaptable to many tasks — and Copilot is an orchestrator, not a model.

A foundation model is a large general model adaptable to many tasks. The lecture names GPT, BERT, GAN, VAE and RNN.

concept GAN

Generative Adversarial Network — a generative type.

concept VAE

Variational Autoencoder — autoencoder-based generative model (see the Autoencoder Neural Network slide).

concept RNN

Recurrent Neural Network — sequence-processing type.

Transformer model implementations

  • Google's BERT was one of the first Transformer-based LLMs.
  • OpenAI's GPT followed: GPT-2, GPT-3, GPT-3.5, GPT-4, ChatGPT.
  • Meta's Llama matches models 10 times its size.
  • Google's PaLM spans text, images and robotics.
  • OpenAI's DALL-E makes images from text descriptions.
  • Florida and Nvidia's GatorTron analyses medical records.
  • DeepMind's AlphaFold 2 predicts protein folding.
  • AstraZeneca and Nvidia's MegaMolBART generates drug candidates.

Where is Copilot?

Unlike GPT or BERT, Copilot isn't one neural network; it is a coordination layer that retrieves data, chooses models, reasons and produces a grounded response.

User Request→ Retrieval→ Model Selection→ Reasoning→ Grounded Response
  • User Request starts outside the model.
  • Retrieval pulls in documents, emails, files, context.
  • Model Selection chooses a GPT-class model.
  • Reasoning applies multi-step inference.
  • Grounded Response uses retrieved enterprise data.

The pipeline sits inside Copilot, emphasising orchestration.

Key Takeaways

If you remember nothing else, remember this.

1

Deep learning networks learn by adjusting weights — connected processing units that improve predictions over time.

2

Nodes compute in five steps — receive, multiply, sum, activate, produce (RMSAP).

3

Depth means many hidden layers — input layer takes raw data, hidden layers extract features, output layer predicts.

4

Weights are the learned dials, and “parameters” means weights — more parameters means more capacity.

5

Training minimises a loss function — give input, get a prediction, compare to the correct answer, measure the error.

6

Backpropagation assigns blame backwards — it finds each weight's error contribution and nudges weights to reduce future error.

7

Learning over time is a loop — forward pass, loss, backpropagation, repeated; errors fall and predictions improve.

8

9

Pretraining has eight steps — collect, clean, tokenize, set objectives, initialise, train with backprop, learn representations, output.

11

12

Generation is autoregressive — tokenize, embed, attend, predict a distribution, sample, append, repeat until a stop token.

Glossary

Every term you need to speak this week's language.

Deep learning network
A type of neural network made of many connected processing units that learn patterns from data by adjusting weights.
Node (neuron)
The basic computational unit: it receives inputs, multiplies them by weights, sums, applies an activation function and produces an output.
Activation function
The rule applied inside a node that decides how strongly it fires after summing its weighted inputs.
Weight (and parameter)
A number on a connection between nodes that controls how strongly one node influences another; “parameter” is a synonym for weight.
Token
A chunk of text — a word, subword or character sequence — that the model converts into a numerical ID.
Positional encoding
Information added to embeddings so the model knows word order and the distance between tokens.
Self-attention
The mechanism that compares each token with all others, computes attention scores, and weights the most relevant tokens more heavily.
Transformer
The model architecture built from embedding layers, positional encoding, multi-head self-attention and feed-forward layers.
Next-token prediction
The training objective where the model predicts the next token given previous tokens; used by GPT-style models.
Masked-language modelling
The training objective where random tokens are hidden and the model predicts the missing words; used by BERT-style models.
Autoregressive model
A model that generates text by appending each predicted token and feeding it back to predict the next.
Training
The process of teaching a network to make accurate predictions by comparing its outputs to correct answers.
Backpropagation
The algorithm that updates weights by propagating error backward through the network.
Pretraining
The phase where a model learns general language patterns from massive amounts of text before task adaptation.
Fine-tuning
Adapting a pretrained model to specific tasks by training either the final layers or the whole model.
Feature extraction (repurposing)
Treating the pretrained model as a fixed feature extractor and training only the final layers while the rest stays frozen.
Full fine-tuning
Training the entire model on task-specific data so all layers are adjusted; used when the dataset is large and very different.
Sampling strategy
The rule for picking the next token — greedy decoding, temperature scaling, or top-k / top-p sampling.
Loss function
The measure of prediction error that training aims to minimise; smaller loss means a better model.
Capacity
The rough potential of a model to fit complex patterns, related to its number of parameters.

Q1

What is a deep learning network, and what does it mean to say it “learns”?

Answer: It is a type of neural network made of many connected processing units that learn patterns from data by adjusting numerical weights. Learning means repeatedly passing data through layers of nodes, measuring the error with a loss function, and using backpropagation to adjust the weights so predictions improve over time.
Q2

List, in order, the five things every node does.

Answer: (1) Receives numerical inputs; (2) multiplies them by weights; (3) sums the results; (4) applies an activation function; (5) produces an output. Mnemonic: RMSAP.
Q3

What makes a network “deep”, and what are the three layer roles?

Answer: Having many hidden layers between input and output is what makes it deep. The input layer receives raw data (such as pixel values or token IDs), hidden layers perform intermediate processing and feature extraction, and the output layer produces the final prediction. Each layer passes information forward.
Q4

Why is “parameter” a synonym for “weight”, and what does having more parameters buy a model?

Answer: A parameter is a weight — a learned number on a connection between nodes. So a model trained on “400B parameters” has 400 billion weights. More parameters means more potential capacity: a larger ability to fit complex patterns, which lets the model be more complex and perform more tasks. The parameters are the model's features, such as generating text, translating and summarising.
Q5

Walk through one training cycle. What role does the loss function play?

Answer: A cycle is: forward pass (feed input and make a prediction), loss calculation (measure how wrong the prediction is using the loss function), then backpropagation (adjust weights to reduce that error next time). The loss function is the scoreboard — training's goal is to minimise it, over many examples and many repetitions.
Q6

Explain backpropagation to a friend who has never heard of it.

Answer: After the network makes a prediction, backpropagation works out how much error each weight contributed to the final output, sends that error information backwards through the network (from output toward input), and adjusts each weight slightly to reduce future error. In plain terms, it tells each weight how to change to make the network better. It never changes the architecture — it only nudges existing weights.
Q7

What are the two phases of an LLM, and what happens in each?

Answer: Training and generating. Training: data collection, tokenization, formatting tokenized data into input–output pairs, training a Transformer to predict output from input, then fine-tuning on specific tasks. Generating: tokenize the input text, predict the next tokens, sample a token from the distribution, append it and repeat until a stopping criterion is met. The Transformer is the model used by ChatGPT.
Q8

List the eight pretraining steps in order.

Answer: (1) Data collection; (2) data cleaning and filtering; (3) tokenization; (4) creating training objectives; (5) Transformer model initialisation; (6) training with backpropagation; (7) learning language representations; (8) pretrained model output. Mnemonic: CCTOITLP.
Q9

Why is pretraining called “unsupervised”, and how do the two training objectives differ?

Answer: It is unsupervised because no human labels are required — the text itself provides the supervision. Next-token prediction (GPT-style) takes previous tokens and predicts the next one. Masked-language modelling (BERT-style) hides random tokens in a sentence and predicts the missing words.
Q10

What are the four components of the Transformer, and why is positional encoding needed?

Answer: Embedding layers, positional encoding, multi-head self-attention and feed-forward layers. Positional encoding is needed because embeddings capture what a token means but not where it occurs; adding position tells the model the word order and the distance between tokens. At initialisation the parameters are random, and their number can range from millions to hundreds of billions.
Q11

Describe self-attention and give one ambiguity it can resolve.

Answer: For each token, self-attention compares it with all other tokens in the input, computes attention scores indicating which tokens are most relevant, and weights information from important tokens more heavily. This lets the model track long-range dependencies, use context dynamically, and resolve ambiguity — for example, working out what “it” refers to in a sentence.
Q12

What happens between the Transformer outputting probabilities and you seeing text?

Answer: A sampling strategy (greedy decoding, temperature scaling, or top-k / top-p sampling) selects a token, balancing coherence against creativity. The chosen token is appended to the input sequence, fed back into the Transformer, and used to predict the next token. This autoregressive loop repeats until a stop token is reached or a maximum length is exceeded. Example distribution: “model” → 0.42, “system” → 0.21, “process” → 0.11.
Q13

Compare feature extraction and full fine-tuning. When would you pick each?

Answer: Feature extraction (repurposing) treats the pretrained model as a fixed feature extractor: only the final layers are trained on task-specific data while the rest stays frozen — cost-effective and efficient. Full fine-tuning trains the entire model, adjusting all layers; it is best when the task-specific dataset is large and significantly different from the pretraining data, giving a more profound adaptation but requiring more resources.
Q14

How is Copilot different from GPT or BERT?

Answer: Copilot is not just one neural network. It is a coordination layer that retrieves data, chooses models, applies reasoning and produces a grounded response. Its pipeline is: User Request → Retrieval (documents, emails, files, context) → Model Selection (an appropriate GPT-class model) → Reasoning (depth and multi-step inference) → Grounded Response (using retrieved enterprise data). The whole pipeline sits inside Copilot, emphasising orchestration.
