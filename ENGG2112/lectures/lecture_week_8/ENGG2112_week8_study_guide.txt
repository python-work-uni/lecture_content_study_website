SECTION 1: What Deep Learning Networks Are
------------------------------------------------
A **deep learning network** is a type of neural network made up of many connected processing units that learn patterns from data by adjusting numerical values called **weights**. Think of it as a huge programmable filter that starts out blank and slowly tunes itself until it can turn messy input into useful predictions.

The learning recipe has three moves that repeat forever: pass data **through** layers of nodes, **measure** the error, then use **backpropagation** to adjust the weights so predictions improve over time.

- **Nodes (Neurons)** — the basic computation units.
- **Layers** — how the nodes are organised.
- **Weights** — the dials that get tuned.
- **Training** — the process of teaching the network.
- **Backpropagation** — the algorithm that updates weights.
- **Learning over time** — the repeated cycle that steadily reduces error.

💡 **Why It Matters:** Almost every modern AI tool is a deep learning network at heart. If you understand nodes, layers, weights, training, and backpropagation, the rest of generative AI is just these ideas at enormous scale.

🧠 **Memory Hook:** A deep network is a *machine that learns by trial and error* — predict, measure the mistake, nudge the weights, repeat.

------------------------------------------------
SECTION 2: Nodes And Layers
------------------------------------------------
### Nodes (Neurons)

**Nodes**, also called **neurons**, are the basic computational units of the network. Each node does the same small job again and again, which is why networks scale to billions of units.

Every node:

1. Receives numerical inputs.
2. Multiplies each input by a weight.
3. Sums the results.
4. Applies an activation function (a rule that decides how strongly the node fires).
5. Produces an output that flows to the next layer.

Nodes represent learned features of the data — early nodes pick up simple patterns, later ones combine them into complex concepts.

### Layers

Deep learning networks are organised into layers:

- **Input layer** — receives the raw input data (e.g. pixel values, token IDs).
- **Hidden layers** — perform intermediate processing and feature extraction. Having many hidden layers is what makes a network "deep".
- **Output layer** — produces the final prediction or output.

Each layer passes information forward to the next layer.

```
Input layer → Hidden layers → Output layer
```

**Node output**: `a = f(sum of w_i * x_i)`

⚠️ **Common Trap:** "Deep" does not mean complicated maths — it literally means *many hidden layers stacked up*. Depth is about how many layers sit between input and output.

🧠 **Memory Hook:** Read the layers left to right like an assembly line: **I**nput feeds **H**idden which feeds **O**utput (IHO).

------------------------------------------------
SECTION 3: Weights And Parameters
------------------------------------------------
**Weights** are numerical values on the connections between nodes. They control how strongly one node influences another — like the volume dial on each wire.

Learning is essentially finding better values for these weights. The architecture stays fixed; training only tunes those numbers. Large models (like LLMs) can have **millions or billions of weights**.

### Parameters Are Weights

"**Parameters**" is a synonym for "weights". When one lab says it trained a model with 400B parameters and another says 600B, both are counting the number of weights in the network.

- More parameters means more **capacity** — a larger potential ability to fit complex patterns in the training data.
- The parameters are the model's features, such as generating different types of text, translating languages, and summarising text.
- More parameters lets a model be more complex and perform more tasks.

⚠️ **Common Trap:** Parameters are not documents or examples stored inside the model. They are learned numbers (weights) on the connections. The training text is not saved as-is.

------------------------------------------------
SECTION 4: Training And Loss
------------------------------------------------
**Training** is the process of teaching the network to make accurate predictions. It is trial and error with a scoreboard: show an example, let the network guess, then tell it how wrong it was.

Training involves:

- Providing input data.
- Producing an output (a prediction).
- Comparing the prediction to the correct answer.

The goal is to **minimise error**, which is measured using a **loss function** — a score for how far the prediction is from the truth. The smaller the loss, the better the model. Training happens over many examples and many repetitions.

### The Core Loop

1. Forward pass — feed the input through the network to get a prediction.
2. Loss calculation — measure how wrong the prediction is.
3. Backpropagation — adjust the weights to reduce that error next time.

✅ **Exam Tip:** If asked what training optimises, the answer is the loss function — the network adjusts weights to make loss as small as possible.

------------------------------------------------
SECTION 5: Backpropagation
------------------------------------------------
**Backpropagation** is the algorithm used to update the weights. Once the network has made a prediction and the loss is known, it needs to know which weights are to blame, and by how much.

It works by:

- Calculating how much error each weight contributed to the final output.
- Sending this error information backwards through the network (from the output layer back toward the input).
- Using this information, adjusting each weight slightly to reduce future error.

In simple terms, **backpropagation tells each weight how to change to make the network better.**

```
Forward pass → Loss → Backpropagate errors → Adjust weights
```

ℹ️ **Note:** The forward pass and the backward pass are two directions of the same network. Data flows forward to make a prediction; blame flows backward to fix the weights.

⚠️ **Common Trap:** Backpropagation does not change the architecture or add neurons. It only nudges the existing weights a little at a time.

------------------------------------------------
SECTION 6: Learning Over Time
------------------------------------------------
Learning is not a single step — training consists of repeated cycles of the same three stages.

- **Forward pass** — make a prediction.
- **Loss calculation** — measure the error.
- **Backpropagation** — update the weights.

Over time:

- Errors decrease.
- The network learns useful representations of the data.
- Predictions become more accurate.

🧠 **Memory Hook:** Think of tuning a guitar string. Each pass you compare the note (loss) and tighten or loosen slightly (weights) until it sounds right — then repeat for every song.

------------------------------------------------
SECTION 7: LLM Two Phase Process
------------------------------------------------
Large Language Models work through a **two phase process**: **training** and **generating**.

### Phase 1 Training

- Data collection.
- Tokenization.
- Format tokenized data into input-output pairs.
- Train a **Transformer** model to predict output from input. (The Transformer is the model used by ChatGPT.)
- Fine-tune using specific tasks.

### Phase 2 Generating

- Tokenize the input text.
- Predict the next tokens.
- Sample a token from this distribution.
- Append the token and repeat.
- Continue until a stopping criterion is met.

```
Training (learn weights) → Generating (use frozen weights to produce text)
```

------------------------------------------------
SECTION 8: Pretraining Pipeline
------------------------------------------------
**Pretraining** is the phase where a model learns general language patterns from massive amounts of text, before being adapted to specific tasks. It has eight steps.

1. Data collection.
2. Data cleaning and filtering.
3. Tokenization.
4. Creating training objectives.
5. Transformer model initialisation.
6. Training with backpropagation.
7. Learning language representations.
8. Pretrained model output.

```
Collect → Clean & filter → Tokenize → Set objectives → Initialise → Train (backprop) → Learn representations → Pretrained model
```

### Data Collection

Goal: expose the model to a wide range of language use, styles, and domains. Gather very large, diverse text corpora. Examples:

- Web pages.
- Books.
- Wikipedia.
- Articles and documents.

### Data Cleaning And Filtering

Goal: improve training stability and model quality. Remove:

- Duplicates.
- Very low-quality text.
- Corrupted or non-linguistic data.

Optional filtering may be applied for language, length, and formatting consistency.

⚠️ **Common Trap:** Garbage in, garbage out — cleaning is not optional tidying. The lecture links it directly to training stability and model quality.

------------------------------------------------
SECTION 9: Training Objectives
------------------------------------------------
The model is trained using **unsupervised learning** — a keyword meaning no human labels are required. Instead, the text itself provides the supervision. Examples of training objectives:

- **Next-token prediction** (used by GPT-style models): given previous tokens, predict the next one.
- **Masked-language modelling** (used by BERT-style models): predict missing tokens in a sentence.

| Objective | Used by | Task |
|---|---|---|
| Next-token prediction | GPT-style models | Given previous tokens, predict the next one |
| Masked-language modelling | BERT-style models | Predict missing tokens in a sentence |

------------------------------------------------
SECTION 10: Transformer Architecture
------------------------------------------------
The **Transformer** defines the model architecture. It is built from:

- Embedding layers.
- Positional encoding.
- Multi-head self-attention.
- Feed-forward layers.

At initialisation, parameters (weights) are set **randomly**. The number of parameters can range from millions to hundreds of billions. Structurally it is still a deep network:

- Layers (input → multiple hidden layers → output).
- Neurons (nodes) as computation units.
- Weighted connections between layers.

### Training With Backpropagation

Backpropagation is the process of adjusting a neural network's weights by propagating error backward through the network. For each batch of tokenized text:

- Tokens are passed through the Transformer.
- The model predicts token probabilities.
- A loss function measures prediction error.
- Gradients are computed using backpropagation.
- Parameters are updated using an optimizer.

This is repeated over many **epochs** and massive datasets.

```
Tokens → Transformer → Predicted probabilities → Loss → Gradients → Optimizer updates weights
```

### Learning Language

Through training, the model implicitly learns:

- Grammar and syntax.
- Semantics and meaning.
- Long-range context dependencies.
- Patterns across domains (science, fiction, instructions, etc.).

------------------------------------------------
SECTION 11: Fine Tuning After Pretraining
------------------------------------------------
After pretraining, the model can be **fine-tuned** — adapted to specific tasks. There are two primary approaches.

### Feature Extraction (Repurposing)

- The pre-trained LLM is treated as a **fixed feature extractor**.
- The model has already learned significant language features that can be repurposed for the specific task.
- The final layers are trained on task-specific data while the rest of the model remains **frozen**.
- This is a cost-effective and efficient way to fine-tune LLMs.

### Full Fine Tuning

- Unlike feature extraction, this adjusts the **entire model**, not just the final layers.
- All model layers are adjusted during the training process.
- Best when the task-specific dataset is large and significantly different from the pre-training data.
- It can lead to a more profound adaptation, but requires more resources than feature extraction.

| Aspect | Feature Extraction | Full Fine Tuning |
|---|---|---|
| What is trained | Final layers only | Entire model |
| Rest of model | Frozen | All layers updated |
| Best when | Task is close to pretraining data | Large, very different dataset |
| Cost | Lower | Higher |

SECTION 12: Generating Text Step By Step
------------------------------------------------
When you prompt a pretrained LLM, it turns your words into tokens and predicts what comes next, one token at a time.

1. **Tokenize the prompt** — convert text into tokens (numbers).
2. **Embed tokens** — add meaning and position information.
3. **Apply attention** — focus on relevant tokens in context.
4. **Process with Transformer layers** — refine meaning across layers.
5. **Predict next token** — output probabilities for possible tokens.
6. **Repeat autoregressively** — append the token and generate text step by step.

```
Tokenize → Embed → Attend → Transform layers → Predict → Sample → Append → Repeat
```

### Input Is Tokenized

- The user provides input text (a prompt).
- It is converted into tokens (numbers) using the same tokenizer used during training, and these tokens become the Transformer's input.

Example: "Large language models work by…" → `[1987, 10234, 845, 563, …]`

### Tokens Are Embedded And Positioned

Inside the Transformer:

1. Each token is mapped to a **vector embedding** that represents its meaning.
2. **Positional encoding** is added so the model knows word order and the distance between tokens.

This step gives the model both *what* the tokens are and *where* they occur.

### Attention Computes Token Relationships

The **self-attention mechanism** is the core of how Transformers work. For each token, the model:

- Compares it with **all other tokens** in the input.
- Computes **attention scores** indicating which tokens are most relevant.
- Weights information from important tokens more heavily.

This allows the model to track long-range dependencies, resolve ambiguity (e.g. what "it" refers to), and use context dynamically.

### Transformer Layers Refine Relationships

The input passes through multiple Transformer layers, each made of multi-head self-attention and feed-forward neural networks. Across these layers the model builds rich semantic representations and higher-level abstractions. No learning occurs here — weights are fixed (pretrained).

### Next Token Prediction

At the output of the Transformer, the model computes a **probability distribution over the vocabulary**. Each possible next token has an associated probability. Example:

- "model" → 0.42
- "system" → 0.21
- "process" → 0.11

### Sampling A Token

The model selects the next token using a **sampling strategy**, such as:

- Greedy decoding.
- Temperature scaling.
- Top-k or top-p sampling.

This balances **coherence** (safe, predictable tokens) and **creativity** (more varied outputs).

### Autoregressive Generation Loop

The selected token is:

- Appended to the input sequence.
- Fed back into the Transformer.
- Used to predict the next token.

This loop repeats until a **stop token** is reached or a **maximum length** is exceeded. This is why LLMs are called **autoregressive models**.

🧠 **Memory Hook:** Generation = **TEAPR** — "Tokenize, Embed, Attend, Predict, Repeat".

SECTION 13: Foundation Models And Copilot
------------------------------------------------
A foundation model is a large general model that can be adapted to many tasks. The lecture names several types of foundation models: **GPT, BERT, GAN, VAE, and RNN**.

### GPT And BERT

| Feature | GPT | BERT |
|---|---|---|
| Full name | Generative Pre-trained Transformer | Bidirectional Encoder Representations from Transformers |
| Direction | Autoregressive, each token sees only earlier tokens | Fully bidirectional, every token attends to all other tokens |
| Training objective | Next-Token Prediction | Masked Language Modelling |
| Method | Predicts the next token given all previous tokens | Random tokens are hidden and the model predicts the missing words |
| Goal | Generate language | Understand language |

### Other Foundation Model Types

- **GAN** — Generative Adversarial Network, listed in the lecture as a type of foundation model.
- **VAE** — Variational Autoencoder, an autoencoder-based generative model (the lecture includes an Autoencoder Neural Network slide).
- **RNN** — Recurrent Neural Network, another neural network type listed among the foundation models.

ℹ️ **Note:** GPT and BERT are Transformer-based; GAN, VAE, and RNN are other foundation-model types the lecture names. The different goals matter — GPT *generates* language while BERT *understands* it.

### Transformer Model Implementations

- Google's **BERT** was one of the first LLMs based on transformers.
- OpenAI's **GPT** followed, with iterations GPT-2, GPT-3, GPT-3.5, GPT-4, and ChatGPT.
- Meta's **Llama** achieves comparable performance with models 10 times its size.
- Google's **Pathways Language Model** generalises across text, images, and robotic controls.
- OpenAI's **DALL-E** creates images from a short text description.
- The University of Florida and Nvidia's **GatorTron** analyses unstructured data from medical records.
- DeepMind's **AlphaFold 2** describes how proteins fold.
- AstraZeneca and Nvidia's **MegaMolBART** generates new drug candidates based on chemical structure data.

### Where Is Copilot

Unlike GPT or BERT, Copilot isn't just one neural network. It's a **coordination layer** that retrieves data, chooses models, applies reasoning, and produces a grounded response.

```
User Request → Retrieval → Model Selection → Reasoning → Grounded Response
```

- **User Request** — starts outside the model.
- **Retrieval** — pulls in relevant documents, emails, files, and context.
- **Model Selection** — dynamically chooses an appropriate GPT-class model.
- **Reasoning** — applies depth and multi-step inference.
- **Grounded Response** — produced using retrieved enterprise data.

The whole pipeline is enclosed within Copilot, emphasising **orchestration**.

KEY TAKEAWAYS
================================================
1. **Deep learning network** — connected processing units that learn patterns by adjusting weights.
2. **Nodes compute in five steps** — receive inputs, multiply by weights, sum, apply an activation function, produce output.
3. **Depth means many hidden layers** — input layer takes raw data, hidden layers extract features, output layer predicts.
4. **Weights are the learned dials** — training finds better weight values, and "parameters" just means weights.
5. **Training minimises a loss function** — give input, get a prediction, compare to the correct answer, measure the error.
6. **Backpropagation assigns blame backwards** — it finds each weight's error contribution and nudges weights to reduce future error.
7. **Learning over time is a loop** — forward pass, loss, backpropagation, repeated; errors fall and predictions improve.
8. **LLMs have two phases** — training (data collection, tokenization, Transformer training, fine-tuning) and generating.
9. **Pretraining has eight steps** — collect, clean, tokenize, set objectives, initialise, train with backprop, learn representations, output.
10. **Objectives need no human labels** — next-token prediction (GPT) and masked-language modelling (BERT) draw supervision from the text.
11. **The Transformer stack** — embeddings, positional encoding, multi-head self-attention, and feed-forward layers; weights start random.
12. **Fine-tuning has two flavours** — feature extraction trains only final layers; full fine-tuning trains everything.
13. **Generation is autoregressive** — tokenize, embed, attend, predict a distribution, sample, append, repeat until a stop token.
14. **Foundation models come in families** — GPT and BERT are Transformer-based; GAN, VAE, RNN are other listed types; Copilot orchestrates.

TERMS TO KNOW
================================================
Deep learning network: A type of neural network of many connected processing units that learn patterns from data by adjusting weights.
Nodes: The basic computational units of a network, also called neurons, which transform inputs into outputs.
Activation function: A rule applied inside a node that decides how strongly it fires after summing its weighted inputs.
Input layer: The layer that receives the raw input data such as pixel values or token IDs.
Hidden layers: The layers that perform intermediate processing and feature extraction, and whose number makes a network deep.
Output layer: The layer that produces the final prediction or output.
Weights: Numerical values on the connections between nodes that control how strongly one node influences another.
Parameters: A synonym for weights, counting the learned numbers of the model's neural network.
Training: The process of teaching a network to make accurate predictions by comparing its outputs to correct answers.
Loss function: The measure of prediction error that training aims to minimise.
Backpropagation: The algorithm that updates weights by propagating error backward through the network.
Tokenization: Converting raw text into tokens and mapping each token to a numerical ID.
Pretraining: The phase where a model learns general language patterns from massive amounts of text before task adaptation.
Embedding: A vector representation of a token that captures its meaning.
Positional encoding: Information added to embeddings so the model knows word order and the distance between tokens.
Self-attention: The mechanism that compares each token with all others and weights the most relevant tokens more heavily.
Transformer: The model architecture built from embeddings, positional encoding, multi-head self-attention, and feed-forward layers.
Next-token prediction: The training objective where the model predicts the next token given previous tokens.
Masked language modelling: The training objective where random tokens are hidden and the model predicts the missing words.
Fine-tuning: Adapting a pretrained model to specific tasks by training either the final layers or the whole model.
Autoregressive model: A model that generates text by appending each predicted token and feeding it back to predict the next.

CONCRETE EXAMPLES / WORKED SCENARIOS
================================================
### Example 1: Walking a value through one node
Suppose a node receives two inputs, 2 and 3, and its connection weights are 0.5 and 0.4.

1. Multiply each input by its weight: 2 × 0.5 = 1.0 and 3 × 0.4 = 1.2.
2. Sum the results: 1.0 + 1.2 = 2.2.
3. Apply the activation function to 2.2 to produce the node's output.
4. If the final answer was wrong, backpropagation adjusts 0.5 and 0.4 slightly so the next prediction is better.

This tiny calculation, repeated across millions of nodes and billions of weights, is all a deep network is doing.

### Example 2: Tokenizing a prompt
The user types: "Large language models work by…"

- The tokenizer converts the text into tokens using the same tokenizer used during training.
- Those tokens are numbers, e.g. `[1987, 10234, 845, 563, …]`.
- The sequence of numbers becomes the input to the Transformer.

### Example 3: Predicting and sampling the next token
After processing the prompt, the model outputs a probability distribution over the vocabulary:

- "model" → 0.42
- "system" → 0.21
- "process" → 0.11

Greedy decoding would always pick the highest-probability token ("model"), which favours coherence. Temperature scaling or top-k/top-p sampling might pick "system" or "process", which adds creativity. The chosen token is then appended and the loop runs again.

### Example 4: Feature extraction versus full fine-tuning
A pretrained model already knows general English. You want a medical notes summariser.

- Feature extraction (repurposing) — freeze the whole model and train only the final layers on medical data. Cheap and efficient when the task is close to pretraining.
- Full fine-tuning — train every layer on a large, very different medical dataset. More profound adaptation, but far more resources.
